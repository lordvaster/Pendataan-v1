# Logo Directory

Silakan letakkan file logo di direktori ini dengan nama:

1. **logo-kalteng.png** - Logo Pemerintah Provinsi Kalimantan Tengah
2. **logo-barito-timur.png** - Logo Pemerintah Kabupaten Barito Timur

## Spesifikasi Logo:
- Format: PNG dengan background transparan (direkomendasikan)
- Ukuran: Minimal 200x200 pixels
- Rasio: Square atau portrait
- File size: Maksimal 500KB per logo

## Catatan:
Jika logo belum tersedia, sistem akan menampilkan placeholder sementara.
Anda dapat mengganti placeholder dengan logo asli kapan saja dengan nama file yang sama.
